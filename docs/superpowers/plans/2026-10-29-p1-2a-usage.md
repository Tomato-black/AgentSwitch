# P1-2a 用量统计与成本估算实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 从非流式上游响应提取精确 token usage，持久化到请求历史；按渠道/模型聚合；用可编辑价格表估算成本（明确标注估算）。

**Architecture:** protocol 增加 `ExtractUsage(body)`；gateway 在非流式响应落盘前提取并写入 `rec.InputTokens/OutputTokens`；storage request_history 增列（migration v6）；bridge 提供 `UsageReport(days)` 与价格表读写；设置页新增「用量」卡。

**Tech Stack:** Go 1.27、SQLite、MyGo v0.6.2；测试离线。

**Spec:** `docs/product/roadmap.md` P1-2；`docs/product/decisions.md` PD-6。

## Global Constraints

- 不自动 commit。
- **流式请求暂不统计 token**（P1-2b）；UI 明确标注「流式未统计」。
- 不虚构价格：默认价格表为空，成本显示「未配置价格」；用户可编辑 JSON 价格表。
- 成本是估算，不承诺账单级准确。
- 不存 prompt/response 正文；只存 token 数值。

```go
package protocol

import "encoding/json"

// ExtractUsage 从 Anthropic/OpenAI Chat/Responses 非流式响应体中提取 token。
// 只读 usage 字段；缺失或全 0 返回 ok=false。
func ExtractUsage(body []byte) (in, out int, ok bool) {
	var env struct {
		Usage *struct {
			InputTokens      int `json:"input_tokens"`
			OutputTokens     int `json:"output_tokens"`
			PromptTokens     int `json:"prompt_tokens"`
			CompletionTokens int `json:"completion_tokens"`
		} `json:"usage"`
	}
	if err := json.Unmarshal(body, &env); err != nil || env.Usage == nil {
		return 0, 0, false
	}
	in, out = env.Usage.InputTokens, env.Usage.OutputTokens
	if env.Usage.PromptTokens > in {
		in = env.Usage.PromptTokens
	}
	if env.Usage.CompletionTokens > out {
		out = env.Usage.CompletionTokens
	}
	if in == 0 && out == 0 {
		return 0, 0, false
	}
	return in, out, true
}
```

storage `RequestHistoryRepo` 增加：

```go
UsageByChannelModel(sinceMs int64) ([]UsageAggregate, error)
```

`UsageAggregate{Channel, Model string; Requests, InputTokens, OutputTokens int64}`；SQL：

```sql
SELECT channel, model, COUNT(*), COALESCE(SUM(input_tokens),0), COALESCE(SUM(output_tokens),0)
FROM request_history WHERE started_at >= ? GROUP BY channel, model
ORDER BY SUM(input_tokens+output_tokens) DESC
```

bridge `usage.go`：
- 价格表 JSON 存 settings key `usage.prices`，结构 `map[string]struct{Input,Output float64}`（单位：美元/1M token）。
- `PricesJSON()` 返回原始 JSON（空则 `{}`）。
- `SavePricesJSON(raw)` 校验 JSON 与负数，写入 settings。
- `UsageReport(days)`：since = now - days*24h；调用 repo；逐行按 model 查价格；`CostUSD = in/1e6*Input + out/1e6*Output`；无价格行 `Priced=false`；汇总。
