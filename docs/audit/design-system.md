# AgentSwitch 桌面设计系统（2026-10-29 统一规范）

> 本文是第二阶段「统一优化方案」的设计规范。它**不替换**已有视觉方向（中性灰 + 橙主操作 + 卡片流），而是把现有 `uikit/theme.go`、`uikit/widgets.go` 与各页实际用法收敛成一份可执行、可验收的规则。
> 约束：MyGo v0.6.2 原生视图；不改业务语义、不改后端接口；所有规则都能在代码中落地并有测试锚点。

## 1. 设计原则

1. **任务效率优先**：桌面工具的第一目标是让用户快速完成「建渠道 → 建模型 → 接入 → 排障」，装饰让位于信息与操作。
2. **状态必须真实**：网关状态、使用中配置、文件是否过期、任务是否进行中，都显示实际状态，不用按钮态或乐观假设代替。
3. **一个视图一个主操作**：橙色只给当前视图最重要的动作；其余动作降级为软底钮或文本钮。
4. **少而稳**：不新增颜色、字号、圆角、间距档位；新页面复用既有词汇，特殊需求先扩展 token 再使用。
5. **异步可见**：任何可能超过 300ms 的操作都必须有进行中反馈，且不得阻塞渲染线程。
6. **危险动作不默认**：破坏性对话框不得把危险按钮设为默认/自动聚焦；默认动作必须是安全动作。

### 2.3 硬性规则

- **橙不表示状态**：运行中用 Success 绿，降级/冷却用 Warning 琥珀，失败用 Danger 红。
- **不在页面内写 `ui.Hex`**：所有颜色必须来自 `t.*` 或 `uikit.Softs(t)`。tile 的蓝/紫/青轮转色也只能在 `uikit` 内定义。
- **软色只用于「底 + 同组字」**，不得软底配主题橙字等跨组组合。
- 文本对比度：正文/背景 ≥ 4.5:1；次要文本允许 `TextMuted`，但不得再叠加透明度。
- **图表色板**：用量页图表使用 `uikit.ChartColors(t)` 的 8 槽分类色板（状态绿/琥珀/红不得当系列色），网格/基线/坐标轴用 `ChartGrid`/`ChartBaseline`/`ChartAxis`；色值与槽位顺序见 `docs/design/chart-palette.md`。

## 3. 字体与排版

| 角色 | 大小 | 字重 | 颜色 | 用途 |
|---|---|---|---|---|
| 页面标题 | `FontSize+3`（16） | Bold | Text | 每页唯一 |
| 区块标题 | `FontSize`（13） | Bold | Text | 卡片内分区 |
| 正文 | `FontSize`（13） | Regular | Text | 表单、说明 |
| 次要说明 | `FontSize`（13） | Regular | TextMuted | 提示、空态 |
| 微小标签 | `FontSize-2`（11） | Regular | 随徽章 | 徽章、tile 副行 |
| 机器读数 | `FontSize` | Regular | TextMuted | `MonoFont`：地址、令牌、模型 ID、路径、耗时、状态码 |

**等宽字体族必须带回退**：`MonoFont` 改为 `"Menlo, monospace"`（MyGo 的 `Font()` 支持逗号分隔族列表，见 `mygo/ui/element.go:1146-1154`）。当前仅 `"Menlo"` 在 Linux/Windows 不存在，会回退成比例字体，地址/令牌列无法对齐。

规则：

- 每页字号档位不超过 4 个；不得出现 14/15/12 等临时值。
- 所有字号必须乘 `TextScale`（由 `BuildTheme` 统一处理，页面不得直接写 `13`）。
- 机器可复制的值（base URL、令牌、路径、模型名）一律等宽并 `SingleLine()`，避免换行破坏可读性。
- 中文长文案按语义断行，不依赖自动换行把词拆开（既有 `closemodal.go` 的两行文案是正确样例）。

## 4. 间距、圆角与尺寸

- **间距基数 `Spacing=4`**：只允许 `t.Space(1|2|3|4|5|6)`。
- **页面**：内容区 `Padding(16)`；页面块间距 12。
- **卡片**：`Padding(14)`、`Radius(12)`、`Border(1, t.Border)`；卡片内区块间距 10–12。
- **控件**：`Radius(8)`；按钮/输入内边距沿用 `t.Space(1.5, 3.5)`（胶囊）或 6–10（下拉触发器）。
- **胶囊/徽章**：`Radius(999)`。
- **表单**：标签列固定宽 **112**；行间距 8；同一卡片内标签宽度必须一致。紧凑行内标签可用 80，但仅限角色映射/模型列表这类表格化区域。
- **文本域高度档位**：输入 96、预览 200、长预览 240；不得出现 220 等一次性值（统一到 200/240）。
- **页面内容最大宽度**：`≤ 920`，左对齐；避免在 1080 宽窗口里把表单拉成超长输入框。
- **侧栏**：固定 200；导航项高 30、Radius 8；底条贴底。

## 5. 页面骨架

```
┌ Sidebar 200 ┬─ Content Padding 16 ──────────────────┐
│ 品牌行       │ PageHeader（标题 + 计数/说明 + 主操作） │
│ 导航         │ Section / Card …                      │
│              │ …                                     │
│ 网关状态底条 │ （内容整体 Scroll）                    │
└──────────────┴───────────────────────────────────────┘
```

- 每页必须有且只有一个 `PageHeader`：标题（16 Bold，随 textScale）+ 可选计数/说明（TextMuted）+ 右侧主操作。
- 列表页：`PageHeader` 下直接是卡片流/表格，不再重复标题。
- 详情/编辑页：`PageHeader` 左侧为「← 返回列表」文本钮 + 标题；主操作（保存）固定在页头右侧或底部操作行，二选一并全站统一。**建议固定在页头右侧**，长页面也能随时保存。
- **页头固定、内容滚动**：所有页面（列表、详情、设置、接入）主体都必须包 `ui.Scroll(...).Grow(1)`。当前逻辑模型列表、渠道列表、设置页没有 Scroll，超过视口的内容不可达，属于 P0 可达性缺陷。
- 编辑态必须有「取消」与「保存」成对出现；取消/返回前执行脏检查（§7）。
- 侧栏切换页面时保留各自滚动位置的诉求暂不实现（MyGo 每帧重建），但必须在切页前处理未保存草稿（见 §7）。

## 6. 组件规范

### 6.1 按钮层级

| 层级 | 组件 | 用法 |
|---|---|---|
| 主操作 | `PillButton`（橙实心） | 每屏最多 1 个：新建/保存/应用/启动 |
| 次操作 | `SoftButton(kind="act"|"gray")` | 编辑、测试、拉取、更多、返回等 |
| 破坏操作 | `SoftButton(kind="danger")` | 删除、停止网关 |
| 文本操作 | `ui.Button` | 返回列表、取消等低权重动作 |

禁止：同一操作行出现两个橙色主钮；用徽章代替按钮；用 emoji 代替图标。

### 6.2 页签

- 接入页的 Agent 页签改用 **`ui.Tabs`**（支持方向键/Home/End，语义正确），不再用 `SoftButton` 模拟。
- 选中态使用框架 tab 样式，颜色只来自主题；未保存切换确认逻辑保留。

### 6.3 卡片与行

- 列表项优先「卡片行」：左侧 32/40px `Tile`，中间名称 + 徽章 + 单行摘要，右侧操作。
- 行内操作不超过 3 个；其余收进「更多」菜单（现状做法保留）。
- 徽章语义固定：启用=ok、停用=gray、使用中=ok、有 Key=act、无 Key=warn、冷却=warn、目标失效/绑定失效=warn、失败=danger。
- 计数类信息用 `TextMuted` 小字，不用徽章。

### 6.4 表单

- 统一 `FormRow`：`Label(112, TextMuted)` + 控件 `Grow(1)`。
- 必填错误显示在表单底部统一信息区，并在字段失去焦点/保存时出现；错误文案以动词开头（「请填写渠道名称」）。
- 输入框 `Placeholder` 只给格式示例，不重复标签。
- 保存按钮在页头右侧 + 底部操作行二选一；错误信息靠近保存按钮。
- 所有可能阻塞的按钮在任务进行中必须 `Disabled(true)` 并显示 `Spinner` + 进行中文案。

### 6.5 反馈

新增统一 `Feedback` 组件（uikit）：

| kind | 颜色 | 用途 | 呈现 |
|---|---|---|---|
| success | Success / 软色 ok | 保存成功、复制成功、应用成功 | Toast 或内联 |
| warning | Warning / 软色 warn | 部分成功、文件过期、需重新应用 | 内联，持久 |
| error | Danger / 软色 danger | 校验失败、写入失败、拉取失败 | 内联，持久 |
| neutral | TextMuted | 纯信息 | 内联 |

规则：

- **瞬时结果**（复制、保存成功）→ `c.Toast(...)`（框架自带，3 条堆叠、可读屏）。
- **需要用户处理的结果**（应用失败、文件过期、网关未运行）→ 内联 `Feedback`，不能被下一帧覆盖。
- 同一页面不得同时出现两套成功/失败文案风格。
- 错误文案必须包含「发生了什么 + 下一步」（如「应用失败：无法写入 config.toml。请检查文件权限后重试」）。

### 6.6 对话框

- 统一走 `ConfirmDialog` 封装（`uikit`）；内部使用 `ui.AlertDialog`；标题为动作对象（「删除渠道」），正文说明后果与可恢复性。
- 对话框圆角统一 12（与卡片一致）；框架 AlertDialog 固定 10，若无法通过主题覆盖，需在封装内用 `DialogBase` 自绘或记录为唯一例外。
- 对话框宽度默认 420（与关窗模态一致），长引用列表改为紧凑摘要（「等 N 个配置」）或内部滚动，不撑高面板。
- **按钮顺序（强制）**：安全动作放末位。框架会把末位按钮设为 Accent、自动聚焦、Enter 触发，因此破坏性对话框必须写成 `("删除", "取消")`，让「取消」成为默认。这与 2026-10-17 视觉 spec §4 一致，当前代码全部写反，需统一修正。
- 按钮文案用具体动词（「删除渠道」「停止网关」），不用泛化的「确认」。
- Escape 等价取消；点遮罩不关闭（框架默认，保持）。
- 至少提供：删除渠道、删除逻辑模型、删除接入配置、还原备份、停止网关、丢弃未保存编辑。

### 6.7 空态

统一 `EmptyState` 组件：

```
[40px 软色 tile/图标]
标题（Bold）
一句说明（TextMuted）
[可选主操作]
```

- 每页空态只出现一次，且只给一个主操作。
- 空态文案必须指出「下一步在哪」（如「先添加渠道，再回来挂目标」），并可直接跳转。
- 列表非空但无搜索结果时，用「无匹配结果 + 清除搜索」空态，不与首次空态混用。

### 6.8 加载与禁用

- 新增 `Async` 状态模型：`idle | running | done | failed`；页面状态持有 `Running bool`、`Progress string`、`Cancel func()`。
- 进行中：触发按钮 `Disabled`，按钮内或紧邻显示 `Spinner` + 「正在拉取模型…」；超过 5 秒提供「取消」。
- 长任务（拉取模型、测试连通、应用 Codex、目录生成）必须移出渲染线程（goroutine + 完成后 `w.Update`/状态落回主线程）。
- 禁止在渲染回调里直接做网络/文件/子进程调用（现状 P0-1）。

### 6.9 表格与搜索

- 行数 > 20 或需要排序时使用 `ui.Table`（虚拟化、列宽、排序、键盘）。
- 列表页超过 8 项时显示 `ui.SearchField`；搜索状态放在 `state`，切页保留。
- 最近请求使用 `ui.Table`，支持展开查看尝试链（后续批次）。

## 7. 交互约定

| 场景 | 规则 |
|---|---|
| 未保存编辑 | 侧栏切页、返回列表、切换 Agent 页签、关闭编辑器前统一检查脏状态；有修改则弹确认（安全动作默认） |
| 保存 vs 应用 | 保存只落库；保存成功后必须明确提示「还需点『应用』」；主路径提供「保存并应用」（默认）与「仅保存」 |
| 配置过期 | 逻辑模型改名/删除、目标链变化、全局配置变化后，若 live 文件未刷新，接入列表显示「需重新应用」warn 徽章；应用后清除 |
| 破坏性操作 | 两段式：行内按钮只是「武装」，对话框确认才执行；对话框安全默认（§6.6） |
| 长操作 | 进行中禁用重复触发；可取消；失败保留重试入口 |
| 网关未运行 | 应用类按钮保留但禁用，旁边给出原因与「启动网关」入口（不要直接隐藏按钮） |
| 复制 | 复制成功用 Toast；令牌默认掩码，复制才进剪贴板 |
| 键盘 | Tab 顺序符合视觉顺序；对话框 Esc 取消；表格支持上下/Home/End；不新增全局快捷键（暂缓） |

## 8. 文案规范

- 全中文；内部错误码/英文原因不得直接暴露给用户（日志可保留）。
- 动词开头、说明后果、给出下一步：`应用失败：无法写入 ~/.codex/config.toml。请检查文件权限后重试。`
- 数字带单位：`90 秒`、`1,000,000 tokens`、`15:04:05`。
- 模型名、路径、端点用等宽；按钮文案 2–4 字。
- 不使用「请稍候」这类无信息文案；进行中要说明正在做什么。

## 9. 主题与可访问性

- 明暗两套必须同帧成立；任何新组件都要在两边检查对比度。
- **对比度验收基线**（WCAG AA，13px 正文 ≥4.5:1）：
  - 正文/背景、次要文本/背景、软底徽章/字、错误文本/背景必须达标。
  - 已确认修复：主按钮改橙底深字（`AccentText=#18181B`），对比度约 7.4:1。
  - 仍需修复：浅色 Warning 文本 **3.19:1**（降级原因）、TextMuted on 浅色侧栏 4.44:1（边缘不达标）。
- 尊重系统 `TextScale`：字号随主题缩放；**标签/输入宽度用 MinWidth + Grow，不写死像素**，避免放大字体后裁切。
- 表单标签必须用框架 `Label()` 关联输入控件（当前全仓零调用），保证读屏器可理解。
- 长文本（配置名、降级原因）必须 `SingleLine` + 省略号，不允许硬切或撑破行高。
- 焦点环使用 `t.Focus`；禁用态降低对比但不低于 3:1。
- 不使用循环动画；`Spinner` 仅在任务进行中挂载（框架只重绘该控件，不重建整视图）。
- Linux 字体规避保持不变；亮色主题实机复核后再决定是否移除。

## 10. 落地映射（uikit 新增组件）

| 组件 | 文件 | 替代现状 |
|---|---|---|
| `PageHeader` | `uikit/widgets.go` | 各页重复的标题行 |
| `SectionTitle` | 同上 | `Text(...).Bold()` + 说明的重复组合 |
| `FormRow` / `LabelWidth` | 同上 | 96/112/120/140/150 混用 |
| `Feedback(kind, text)` | 同上 | 各页 `Msg` 文本 + 任意颜色 |
| `EmptyState(title, hint, action)` | 同上 | 四页各自手写空态 |
| `AsyncButton` / `LoadingRow` | 同上 | 同步按钮 + 无反馈 |
| `ListRow` 骨架 | 同上 | 渠道/接入/逻辑模型重复行布局 |
| `Tabs` 适配 | `pages/access/access.go` | SoftButton 伪页签 |
| `Toast` 统一出口 | `uikit` 薄封装或直接 `c.Toast` | 复制/保存成功无提示 |

所有新增组件必须配 `uikit` 单测（明暗两态、状态色、尺寸锚点），页面测试复用 `uitest` 夹具。

## 11. 已确认的品牌级决策（2026-10-29）

| 决策 | 结论 |
|---|---|
| 主按钮配色 | 橙底深字：背景 `#F97316`，文字 `#18181B` |
| 危险对话框 | 取消居末位，安全动作获得焦点；危险按钮不使用 Accent 主样式 |
| 接入编辑器形态 | 独立子页/抽屉（批次 3 实施），保留配置列表上下文 |
| Kun 接入 | 不做专门页签；删除 Kun spec，只保留通用「连接指南」 |
| 全局配置卡 | 保留（2026-10-20 spec 的删除决策不采纳） |

## 12. 禁止事项（出现即视为不符合设计系统）

- 在页面代码中写死颜色、字号、圆角、间距。
- 同一页面出现两个橙色主操作。
- 破坏性对话框把危险按钮放末位（会成为 Enter 默认动作）。
- 在渲染回调中执行网络/文件/子进程调用。
- 用 `SoftButton` 模拟页签、用 `Text` 模拟按钮、用 emoji 模拟图标。
- 成功/失败共用同一种视觉样式。
- 空态里出现两个以上同等权重的主操作。
- 未经确认新增页面级动画或常驻 `Loop`。
