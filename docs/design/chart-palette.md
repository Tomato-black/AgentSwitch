# 图表配色规范（2026-10-29）

设置页「用量」的两张原生图表（Token 用量柱状图、响应时长折线图）使用
`uikit.ChartColors(t)` 的 8 槽分类色板。本文记录色值、用途与校验结果。

## 1. 使用规则

- **颜色跟随渠道实体，不跟随排名**：`uikit.ChartSlots(t, names)` 按渠道名
  排序分配槽位，数据刷新导致排名变化时不会换色；两张图共用同一组渠道名，
  同一渠道在柱状图与折线图中同色。
- **状态色不当系列色**：Success 绿 / Warning 琥珀 / Danger 红只表达健康、
  冷却与失败，不进入色板；图例与数据点靠色块 + 名称双重编码，不靠红绿。
- **超过 8 个渠道**时色板循环复用，仍以柱子下方的直接标签、折线图图例
  区分。
- 网格、基线、坐标轴文字一律走 `ChartGrid` / `ChartBaseline` / `ChartAxis`，
  页面代码不得再写 `ui.Hex`。
- 柱顶数值标签优先放在柱外（坐标轴墨色）；空间不足时落在柱内，用
  `ChartInkOn` 在白字与深字之间取对比度更高的一侧。

## 2. 分类色板

顺序即色盲安全机制，不得随意重排。

| 槽位 | 色相 | 浅色（Surface `#FFFFFF`） | 深色（Surface `#2C2C31`） |
|---|---|---|---|
| 1 | 蓝 | `#2563EB` | `#3B82F6` |
| 2 | 橙（品牌邻色） | `#EA580C` | `#EA580C` |
| 3 | 青绿 | `#0D9488` | `#0D9488` |
| 4 | 紫红 | `#A21CAF` | `#A855F7` |
| 5 | 洋红 | `#DB2777` | `#EC4899` |
| 6 | 靛（近蓝，后置） | `#4338CA` | `#6366F1` |
| 7 | 青（近青绿，后置） | `#0891B2` | `#0891B2` |
| 8 | 紫（近紫红，后置） | `#7C3AED` | `#8B5CF6` |

**为什么 slot 3 是青绿而不是靛**：靛与蓝在深色底上的常规视觉 ΔE 只有
7.2（浅色 10.4），旧顺序把靛放在第 3 槽时，3 渠道图中「蓝/靛」两条线难以
区分。前 5 槽改为蓝/橙/青绿/紫红/洋红后，任意两色的常规视觉 ΔE ≥ 15.4，
覆盖最常见的 3–5 渠道场景。靛、青、紫分别与蓝、青绿、紫红过近，后置到
6–8 槽，只在高系列数时出现。

与卡片 Surface 的对比度：

| 槽位 | 浅色 | 深色 |
|---|---|---|
| 1 蓝 | 5.17:1 | 3.78:1 |
| 2 橙 | 3.56:1 | 3.90:1 |
| 3 青绿 | 3.74:1 | 3.71:1 |
| 4 紫红 | 6.32:1 | 3.51:1 |
| 5 洋红 | 4.60:1 | 3.94:1 |
| 6 靛 | 7.90:1 | 3.11:1 |
| 7 青 | 3.68:1 | 3.77:1 |
| 8 紫 | 5.70:1 | 3.28:1 |

全部 ≥ 3:1（图形标记的 WCAG 门槛）。

## 3. 图表底纹与墨色

| 角色 | 浅色 | 深色 | 说明 |
|---|---|---|---|
| 网格 `ChartGrid` | `#EEF0F3` | `#34343A` | 低对比，只做读数辅助 |
| 基线 `ChartBaseline` | `#DCDCE2` | `#4A4A52` | 略强于网格 |
| 坐标轴文字 `ChartAxis` | `#6B6B73` | `#A1A1AA` | 等同 `TextMuted`，5.1:1 / 5.8:1 |
| 色块上的标签 `ChartInkOn` | `#18181B` 或 `#FFFFFF` | 同左 | 按底层色取更高对比的一侧 |

## 4. 标记规格

- 柱子：占槽宽 56%，最大宽 64px，4px 圆角；相邻柱之间留出卡片底色空隙。
- 折线：2px 实线；数据点 5px 圆点，外加 2px 卡片底色描边（`t.Surface`），
  避免交叉/重叠时糊成一片。
- 图例：12×3px 圆角色块 + 中性墨色渠道名；文字不染系列色。
- 不引入渐变、玻璃拟态、阴影或动效。

## 5. 校验记录

使用 dataviz 色板校验器（OKLab ΔE ×100、Machado 2009 色盲模拟）：

```bash
node scripts/validate_palette.js \
  "#2563EB,#EA580C,#0D9488,#A21CAF,#DB2777,#4338CA,#0891B2,#7C3AED" \
  --mode light --surface "#FFFFFF"
node scripts/validate_palette.js \
  "#3B82F6,#EA580C,#0D9488,#A855F7,#EC4899,#6366F1,#0891B2,#8B5CF6" \
  --mode dark --surface "#2C2C31"
```

结果：两套均通过亮度带、色度下限、相邻色盲分离（浅色最差 ΔE 12.4，深色
12.6，目标 ≥ 8）、常规视觉分离（浅色最差 15.8，深色 17.0）与 3:1 对比度
检查。青绿/洋红在色盲模拟下仍较接近（CVD ΔE 3.8 浅 / 6.9 深），因此两者
在槽位顺序上不相邻，并保留直接标签与图例名称作为第二编码。
